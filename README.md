# javascript-darkmode-with-limit-counter

Learning project Sesi 4 - Implementing dark mode with a limit counter.

Features:
- Dark mode toggle button
- Counter showing how many times dark mode was used (e.g., "Darkmode dipakai 1x, tersisa 4")
- Limit feature: After 5x, shows message "FITUR DARK MODE ANDA TELAH MENCAPAI LIMIT" and shows RESTART button
- Light/Dark theme switch with CSS class toggle

Built With:
- HTML, CSS, Vanilla JavaScript

What I learned: DOM manipulation, state counter logic, local storage concept, conditional rendering.
